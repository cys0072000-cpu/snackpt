운동 기록 추가
번호(1. 2. 3.)로 운동을, -로 시작하는 줄은 팁으로, 숫자·kg·x가 섞인 줄은 세트로 자동 인식합니다. 운동 부위도 이름을 보고 자동 분류해요.

화면 테마

밝은 화면과 어두운 화면 중 골라 쓸 수 있어요.

백업 내보내기

모든 팁과 기록을 JSON 파일 하나로 저장합니다. 폰↔PC 옮기거나 브라우저 데이터가 날아갈 때 대비용이에요.

백업 불러오기

내려받은 JSON을 다시 넣습니다. 같은 기록은 건너뛰고 없는 것만 합쳐집니다.

폰 홈 화면에 두기

  1. 폰 사파리·크롬에서 cys0072000-cpu.github.io/snackpt 열기
  2. 공유 → 홈 화면에 추가
  3. 주소창 없는 전체화면 앱으로 실행됩니다

팁·기록은 연 브라우저 안에 저장됩니다. 폰과 PC는 서로 다른 저장소라, 옮길 땐 위의 백업 파일을 쓰세요. 앱이 새 버전으로 갱신돼도 저장된 데이터는 그대로 유지됩니다.

부위 분류를 고치려면

운동 이름으로 자동 분류하지만 틀릴 수 있어요. 종목 카드를 열고 상단 부위칩을 탭하면 바뀌고, 그 운동의 모든 날짜에 한번에 적용됩니다.

영상 붙이는 법

카톡 영상은 시간이 지나면 다운로드가 막힙니다. 받는 날 바로 폰에 저장해 두세요.

  1. 카톡에서 영상 재생 → 저장 (또는 길게 눌러 저장)
  2. 유튜브 앱 → ＋ → 동영상 업로드 → 공개 설정을 미등록으로
  3. 업로드된 영상 → 공유 → 링크 복사
  4. 추가 화면이나 종목 화면의 영상칸에 붙여넣기

앱 안에서 바로 재생: 유튜브 · mp4/mov 직링크
새 탭으로 열림: 구글 드라이브, 구글 포토, 아이클라우드 등

구글 드라이브는 앱 안에서 재생하려 하면 쿠키 동의창만 뜨고 막혀서, 새 탭으로 열도록 해뒀습니다. 앱 안에서 바로 보려면 유튜브를 쓰세요.

아이클라우드 “링크 복사”는 30일 뒤 만료되니 오래 보관할 영상에는 쓰지 마세요.
