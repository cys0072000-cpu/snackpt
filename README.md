# 🍪 스낵PT — 내 손안의 PT 선생님

PT 트레이너가 카톡으로 보내주는 자세 팁을 **운동 부위별로 쌓아두고**, 혼자 운동할 때 꺼내 보는 개인용 앱.

기록장이 아니라 **팁 아카이브**가 중심이다. 지난주 다리 운동에서 배운 것과 오늘 배운 것이 다르니,
"다리" 하나만 누르면 지금까지 다리 운동에서 들은 모든 팁이 종목별로 모여 나온다.

파일 하나(`index.html`)로 끝나는 정적 웹앱. 서버·로그인·설치 없음.

**➡️ https://cys0072000-cpu.github.io/snackpt/**

## 쓰는 법

1. 위 주소를 연다 (폰이면 홈 화면에 추가해두고 아이콘으로)
2. **＋추가** 탭 → 트레이너 카톡 내용을 통째로 붙여넣기 → **✨ 자동 정리**
3. 운동 부위가 자동 분류된다. 틀렸으면 부위칩을 탭해서 고치고 **저장**
4. 헬스장에서는 **🎓PT 팁** 탭 → 오늘 할 부위(다리/가슴/등/어깨) 선택 → **세트 하나 골라서** 그대로 진행

붙여넣은 메시지 하나가 세트 하나가 되므로, 트레이너에게 받은 그날의 구성이 흐트러지지 않는다.

## 4개 탭

| 탭 | 하는 일 |
|---|---|
| 🎓 PT 팁 | **핵심.** 부위별로 세트를 고르거나(기본) 종목별 팁을 모아 본다 |
| 📒 기록 | 날짜순 일지. 언제 뭘 했는지, 중량이 얼마나 올랐는지 |
| ➕ 추가 | 카톡 텍스트 자동 파싱 → 편집 → 저장 |
| ⚙️ 설정 | 백업 내보내기/불러오기, 홈 화면 추가 안내 |

### 🎓 PT 팁 — 두 가지 보기

**운동 세트** (기본)
**한 번에 붙여넣은 카톡 메시지 하나 = 세트 하나**로 통째로 묶인다.
부위를 고르면 `다리 운동 #1`, `#2`, `#3` … 이 나오고, 오늘 할 걸 하나 고르면 된다.

> 오늘 하체하는 날이네 → **다리** 탭 → **다리 운동 #2** 선택 → 그 화면 보면서 운동

세트를 열면 종목이 순서대로, 팁·세트별 중량·영상까지 다 들어 있다. 그대로 따라 하면 되는 화면.

**종목별 팁**
"바벨 스쿼트에 대해 지금까지 배운 것 전부"를 종목 단위로 모아 본다.
팁 전체, 별표, 직접 추가, 자세 영상, 중량 이력이 한 화면에 있다.

### 세트의 부위는 어떻게 정해지나

세트 안에서 **가장 많은 종목이 속한 부위**로 정해진다. 같으면 첫 종목 기준.
가슴 2 + 어깨 1이면 "가슴 운동 #N"이 되고, 어깨 종목도 그 세트 안에 그대로 들어 있다.

틀렸으면 세트를 열고 상단 부위칩을 탭하면 바뀐다. 번호는 부위별로 오래된 것부터 자동으로 매겨지고,
세트를 지우면 뒷 번호가 하나씩 당겨진다.

### 중량 이력

같은 종목이 여러 세트에 나오면 **세트 화면과 종목 화면 양쪽 모두**에 그 종목의 전체 중량 이력이 붙는다.

```
📊 중량 이력 · 3회
  8/3 월                        25kg  ▲+5
    1세트   25kg × 15회
    2세트   25kg × 12회
  7/27 월  [지금]                20kg  ▲+5
    1세트   20kg × 15회
    2세트   20kg × 12회
  7/13 월                       15kg
    1세트   15kg × 15회
    2세트   15kg × 15회
    3세트   15kg × 15회
```

세트는 한 줄에 몰지 않고 **1세트·2세트… 로 나눠서** 적는다.
지금 보고 있는 세트는 `지금` 표시와 함께 강조되고, 직전 회차 대비 증감이 붙는다. 탭하면 그 세트로 바로 넘어간다.
`다리 운동 #1`을 열어도 "이 이너타이는 그 뒤로 20kg, 25kg까지 올라갔구나"가 같이 보인다.

### 뒤로가기

세트 → 종목 팁 → 이력에서 다른 세트… 로 파고들어도 한 단계씩 되돌아온다.

- **화면 왼쪽 끝(28px 이내)에서 오른쪽으로 스와이프** — 끄는 만큼 화면이 따라오고, 68px 넘게 끌면 뒤로
- 안드로이드 **뒤로가기 버튼**, 브라우저 뒤로가기 (`history` 연동)
- PC에서는 **Esc**
- 좌측 상단 버튼은 상황에 따라 바뀐다 — 파고든 상태면 `‹`(뒤로), 첫 화면이면 `✕`(닫기)
- `✕`는 몇 단계를 팠든 한 번에 닫으며, 쌓인 history도 정확히 되감는다

홈 화면에 추가한 앱은 사파리 자체 스와이프가 없어서 직접 구현했다.
세로 스크롤·화면 가운데 스와이프와는 섞이지 않는다.

### 핵심 팁 자동 선별

선생님이 **두 번 이상 반복한 팁**은 그 사람의 핵심 교정 포인트라, 자동으로 맨 위 "⭐ 핵심 팁"으로 올라가고
`3번 들음 · 7/13, 7/27, 8/3` 처럼 언제 들었는지 표시된다. 별표(☆)를 직접 눌러 고정할 수도 있다.

말로만 듣고 카톡에 없던 팁은 종목 상세 하단에서 **직접 추가**하면 된다.

## 운동 부위 자동 분류

운동 이름을 보고 **다리 / 가슴 / 등 / 어깨 / 팔 / 코어 / 기타** 로 나눈다.
기본 4부위(다리·가슴·등·어깨)는 비어 있어도 칩이 보이고, 나머지는 기록이 생겨야 나타난다.

```
바벨 스쿼트, 레그프레스, 런지, 힙쓰러스트, 루마니안 데드리프트   → 다리
이너타이, 아우터타이, 힙 어덕션/어브덕션, 레그컬, 카프레이즈     → 다리
벤치프레스, 인클라인 덤벨 프레스, 케이블 플라이, 딥스           → 가슴
랫풀다운, 시티드 로우, 풀업, 데드리프트, 풀오버                → 등
숄더프레스, 사이드 래터럴 레이즈, 페이스풀, 업라이트 로우, 슈러그 → 어깨
바벨 컬, 트라이셉스 프레스다운, 킥백                          → 팔
플랭크, 크런치, 행잉 레그레이즈                              → 코어
```

애매한 것들은 규칙 순서로 처리한다 — `업라이트 로우`는 등이 아니라 어깨,
`트라이셉스 프레스다운`은 가슴이 아니라 팔, `루마니안 데드리프트`는 등이 아니라 다리(햄스트링).

**틀렸으면:** 종목 카드를 열고 상단 부위칩을 탭. 그 운동의 **모든 날짜에 한번에** 적용되고 계속 기억한다.
추가 화면의 정리 결과에서 미리 바꿔도 마찬가지로 기억된다.

## 파서가 알아듣는 형식

```
오늘의 운동                          ← 헤더 줄은 자동 무시

1.루마니안 데드리프트                 ← "숫자." 또는 "숫자)" = 새 운동
-호흡 마시고 꽉 잡고…                 ← "-"로 시작 = 팁
10kg x 15, 20kg x 10, 40kg x 5, 6 5set   ← 세트 줄

오늘도 고생 많으셨습니다~!            ← 인사말은 자동 제외
```

- `40kg x 5, 6` → 40kg 5회 + 40kg **6회** (중량을 이어받음)
- `5kg x 15, 15, 15, 15 4set` → 5kg 15회 4세트
- `30 x 15` → 단위 없으면 kg으로 처리
- `30초, 45초` → 시간 세트
- 세트를 여러 줄에 나눠 써도 합쳐짐
- 메시지 안의 유튜브/드라이브 링크는 해당 운동 영상으로 자동 연결
- `8월 5일`, `2026.08.05` 같은 날짜가 있으면 날짜칸 자동 입력
- 원문 표기 세트 수(`5set`)와 실제 파싱 개수가 다르면 노란 뱃지로 알려줌

형식이 달라 못 알아들어도 파싱 결과 화면에서 직접 고치면 되고, **＋운동 직접 추가**로 처음부터 입력할 수도 있다.

## 저장 방식

- 팁·기록·별표·부위지정 전부 **연 브라우저의 localStorage**에 저장된다. 서버로 나가지 않는다
- 폰과 PC는 서로 다른 저장소 → 옮길 땐 **설정 → 백업 파일 내려받기**(JSON) 후 반대쪽에서 불러오기
- 불러오기는 병합 방식(같은 날짜+같은 운동 구성이면 건너뜀)
- 브라우저 데이터 삭제·시크릿 모드는 기록이 날아가므로 가끔 백업 권장

## 폰에서 열기

1. 사파리(아이폰) / 크롬(안드로이드)에서 **https://cys0072000-cpu.github.io/snackpt/** 열기
2. **공유 → 홈 화면에 추가**
3. 앱 아이콘처럼 실행된다 (주소창 없는 전체화면 모드)

> **파일을 폰에 옮겨서 여는 방식은 쓰지 않는다.** iCloud·카톡으로 HTML을 보내면 파일 앱의 미리보기로 열리는데,
> 사파리가 아니라서 입력한 팁이 저장되지 않고 홈 화면 추가도 안 된다. 반드시 위 웹주소로 연다.

### 배포 / 업데이트

GitHub Pages(`cys0072000-cpu/snackpt`, main 브랜치 루트)로 서비스된다.
코드를 고친 뒤 push하면 1~2분 안에 폰에도 반영된다.

```bash
cd projects/snackpt
git add -A && git commit -m "설명" && git push
```

저장소는 공개지만 **올라가는 건 빈 앱 껍데기뿐**이다. 팁·기록·영상 링크는 전부 각자 브라우저의
localStorage에만 있고 저장소에는 들어가지 않는다. 앱을 새 버전으로 갱신해도 저장된 데이터는 그대로 유지된다.

## 영상 붙이기

> **카톡 영상은 유효기간이 있다.** 받은 지 시간이 지나면 "저장 기간이 만료되었습니다"로 다운로드가 막힌다.
> 톡서랍 구독 중이 아니라면 **받는 날 바로 폰에 저장**하는 게 먼저다.

**추천 — 유튜브 미등록 업로드** (무료·무제한·영구 보관·앱 안에서 재생)

1. 카톡에서 영상 재생 → 저장
2. 유튜브 앱 → ＋ → 동영상 업로드 → 공개 설정 **미등록(일부 공개)**
3. 공유 → 링크 복사 → 영상칸에 붙여넣기

영상이 쌓였다면 PC 유튜브 스튜디오에서 한 번에 드래그 업로드하는 편이 빠르다.

**링크 종류별 동작**

| 링크 | 앱에서 |
|---|---|
| 유튜브 (일반·쇼츠·youtu.be) | 앱 안에서 바로 재생 |
| mp4 / mov / m4v / webm 직링크 | 앱 안에서 바로 재생 |
| 구글 드라이브 | 새 탭으로 열림 |
| 구글 포토, 아이클라우드, 그 외 | 새 탭으로 열림 |

> 구글 드라이브는 iframe 안에서 제3자 쿠키가 차단돼 쿠키 동의창만 뜨고 재생되지 않는다.
> 그래서 인라인 재생을 시도하지 않고 새 탭으로 넘긴다. 앱 안에서 바로 보려면 유튜브를 쓸 것.

- 아이클라우드 "링크 복사"는 **30일 뒤 만료**되니 오래 보관할 영상에는 쓰지 않는다
- 영상은 탭했을 때만 불러오므로 데이터를 아낀다
- 같은 종목에 여러 날짜의 영상이 붙으면 종목 화면에 날짜별로 모두 모인다

## 성능

주기적으로 도는 것이 아무것도 없다. `setInterval`·애니메이션 루프·네트워크 폴링 0건이고,
모든 `setTimeout`은 사용자 동작에 한 번씩만 걸린다. 상시 이벤트 리스너는 6개(터치 4·popstate·keydown)로 고정.
화면을 켜두고 방치해도 CPU·램을 쓰지 않는다.

목록은 **60개씩 끊어 그리고** "＋ N개 더 보기"로 이어 붙인다. 검색 입력은 120ms 디바운스.
덕분에 기록이 몇 년 쌓여도 DOM 노드 수와 렌더 시간이 일정하게 유지된다.

| 데이터 | 렌더 | DOM 노드 | 저장 용량 |
|---|---|---|---|
| 104세트 (1년) | 8ms | 2,429 | 82KB |
| 520세트 (5년) | 6ms | 2,429 | 411KB |
| 1,040세트 (10년) | 8ms | 2,429 | 822KB |

브라우저 localStorage 한도가 보통 5MB이므로 10년치를 넣어도 6분의 1 수준이다.
시트를 200번 열고 닫아도 힙 증가는 없다(누수 없음).

## 기술 메모

- 순수 HTML/CSS/JS 단일 파일, 외부 라이브러리·네트워크 요청 없음 (유튜브 임베드 제외)
- 다크/라이트 테마 자동 + 우상단 ◐ 버튼으로 수동 전환
- 데이터 스키마 (v2, v1 데이터는 열 때 자동 이관)

```jsonc
{
  "version": 2,
  "sessions": [{
    "id": "s...", "date": "2026-08-03", "memo": "", "createdAt": 0,
    "exercises": [{
      "name": "루마니안 데드리프트",
      "part": "leg",                              // 자동 분류 결과
      "cues": ["호흡 마시고…"],                    // = 팁
      "sets": [{ "w": 40, "u": "kg", "r": 5 }],   // w=중량, u=단위, r=횟수, t=시간
      "declared": 5,                              // 원문에 적힌 세트 수
      "rawSets": "10kg x 15, …",
      "video": ""
    }]
  }],
  "parts":  { "루마니안데드리프트": "back" },       // 종목 부위 수동 지정 (자동 분류보다 우선)
  "sparts": { "s2abc…": "shoulder" },              // 세트 부위 수동 지정 (다수결보다 우선)
  "stars": { "바벨스쿼트|무릎이발끝방향…": true },   // 별표한 팁
  "notes": [{ "id":"n...", "ex":"바벨스쿼트", "exName":"바벨 스쿼트",
              "text":"발 너비는 어깨보다 살짝 넓게", "date":"2026-08-03" }]
}
```

팁 중복 판정은 공백·문장부호를 지운 문자열로 하므로, 표현이 조금 달라도(`,` 유무 등) 같은 팁으로 묶인다.
