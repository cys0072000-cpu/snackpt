# 🍪 스낵PT — 내 손안의 PT 선생님

PT 트레이너가 카톡으로 보내주는 자세 팁을 **운동 부위별로 쌓아두고**, 혼자 운동할 때 꺼내 보는 개인용 앱.

기록장이 아니라 **팁 아카이브**가 중심이다. 지난주 다리 운동에서 배운 것과 오늘 배운 것이 다르니,
"다리" 하나만 누르면 지금까지 다리 운동에서 들은 모든 팁이 종목별로 모여 나온다.

파일 하나(`index.html`)로 끝나는 정적 웹앱. 서버·로그인·설치 없음.

## 쓰는 법

1. `index.html`을 브라우저로 연다
2. **＋추가** 탭 → 트레이너 카톡 내용을 통째로 붙여넣기 → **✨ 자동 정리**
3. 운동 부위가 자동 분류된다. 틀렸으면 부위칩을 탭해서 고치고 **저장**
4. 헬스장에서는 **🎓PT 팁** 탭 → 오늘 할 부위(다리/가슴/등/어깨) 선택 → 종목 카드를 보며 운동

## 4개 탭

| 탭 | 하는 일 |
|---|---|
| 🎓 PT 팁 | **핵심.** 부위별로 종목과 팁을 모아 본다. 종목별 / 날짜별 두 가지 보기 |
| 📒 기록 | 날짜별 세션 카드. 그날 뭘 했는지, 중량이 얼마나 올랐는지 |
| ➕ 추가 | 카톡 텍스트 자동 파싱 → 편집 → 저장 |
| ⚙️ 설정 | 백업 내보내기/불러오기, 홈 화면 추가 안내 |

### 🎓 PT 팁 — 두 가지 보기

**종목별 팁** (기본)
부위를 고르면 그 부위의 모든 종목이 카드로 나온다. 카드마다 그동안 들은 팁이 쌓여 있다.
탭하면 종목 상세가 열리고 — 팁 전체, 별표, 직접 추가, 자세 영상, 중량 이력이 한 화면에 있다.

**날짜별로 보기**
`다리 운동 #1`, `#2`, `#3` … 회차별로 그날 배운 것만 따로 본다.
"지난주 다리 때 뭐라고 하셨더라"를 찾을 때 쓴다.

### 핵심 팁 자동 선별

선생님이 **두 번 이상 반복한 팁**은 그 사람의 핵심 교정 포인트라, 자동으로 맨 위 "⭐ 핵심 팁"으로 올라가고
`3번 들음 · 7/13, 7/27, 8/3` 처럼 언제 들었는지 표시된다. 별표(☆)를 직접 눌러 고정할 수도 있다.

말로만 듣고 카톡에 없던 팁은 종목 상세 하단에서 **직접 추가**하면 된다.

## 운동 부위 자동 분류

운동 이름을 보고 **다리 / 가슴 / 등 / 어깨 / 팔 / 코어 / 기타** 로 나눈다.
기본 4부위(다리·가슴·등·어깨)는 비어 있어도 칩이 보이고, 나머지는 기록이 생겨야 나타난다.

```
바벨 스쿼트, 레그프레스, 런지, 힙쓰러스트, 루마니안 데드리프트   → 다리
벤치프레스, 인클라인 덤벨 프레스, 케이블 플라이, 딥스           → 가슴
랫풀다운, 시티드 로우, 풀업, 데드리프트, 풀오버                → 등
숄더프레스, 사이드 래터럴 레이즈, 페이스풀, 업라이트 로우, 슈러그 → 어깨
바벨 컬, 트라이셉스 프레스다운, 킥백                          → 팔
플랭크, 크런치, 행잉 레그레이즈                              → 코어
```

애매한 것들은 규칙 순서로 처리한다 — `업라이트 로우`는 등이 아니라 어깨,
`트라이셉스 프레스다운`은 가슴이 아니라 팔, `루마니안 데드리프트`는 등이 아니라 다리(햄스트링).

**틀렸으면:** 종목 카드를 열고 상단 부위칩을 탭. 그 운동의 **모든 날짜에 한번에** 적용되고 계속 기억한다.
추가 화면의 정리 결과에서 미리 바꿔도 마찬가지로 기억된다.

## 파서가 알아듣는 형식

```
오늘의 운동                          ← 헤더 줄은 자동 무시

1.루마니안 데드리프트                 ← "숫자." 또는 "숫자)" = 새 운동
-호흡 마시고 꽉 잡고…                 ← "-"로 시작 = 팁
10kg x 15, 20kg x 10, 40kg x 5, 6 5set   ← 세트 줄

오늘도 고생 많으셨습니다~!            ← 인사말은 자동 제외
```

- `40kg x 5, 6` → 40kg 5회 + 40kg **6회** (중량을 이어받음)
- `5kg x 15, 15, 15, 15 4set` → 5kg 15회 4세트
- `30 x 15` → 단위 없으면 kg으로 처리
- `30초, 45초` → 시간 세트
- 세트를 여러 줄에 나눠 써도 합쳐짐
- 메시지 안의 유튜브/드라이브 링크는 해당 운동 영상으로 자동 연결
- `8월 5일`, `2026.08.05` 같은 날짜가 있으면 날짜칸 자동 입력
- 원문 표기 세트 수(`5set`)와 실제 파싱 개수가 다르면 노란 뱃지로 알려줌

형식이 달라 못 알아들어도 파싱 결과 화면에서 직접 고치면 되고, **＋운동 직접 추가**로 처음부터 입력할 수도 있다.

## 저장 방식

- 팁·기록·별표·부위지정 전부 **연 브라우저의 localStorage**에 저장된다. 서버로 나가지 않는다
- 폰과 PC는 서로 다른 저장소 → 옮길 땐 **설정 → 백업 파일 내려받기**(JSON) 후 반대쪽에서 불러오기
- 불러오기는 병합 방식(같은 날짜+같은 운동 구성이면 건너뜀)
- 브라우저 데이터 삭제·시크릿 모드는 기록이 날아가므로 가끔 백업 권장

## 폰에서 열기

1. 이 파일을 iCloud 드라이브 / 구글 드라이브에 올리거나 카톡 "나에게 보내기"로 폰에 옮긴다
2. 사파리·크롬에서 열고 **공유 → 홈 화면에 추가**
3. 앱 아이콘처럼 실행된다 (상태바까지 쓰는 전체화면 모드)

> 파일을 새 버전으로 교체해도 저장된 팁·기록은 유지된다 (데이터는 파일이 아니라 브라우저에 있음).

## 영상 붙이기

> **카톡 영상은 유효기간이 있다.** 받은 지 시간이 지나면 "저장 기간이 만료되었습니다"로 다운로드가 막힌다.
> 톡서랍 구독 중이 아니라면 **받는 날 바로 폰에 저장**하는 게 먼저다.

**추천 — 유튜브 미등록 업로드** (무료·무제한·영구 보관·앱 안에서 재생)

1. 카톡에서 영상 재생 → 저장
2. 유튜브 앱 → ＋ → 동영상 업로드 → 공개 설정 **미등록(일부 공개)**
3. 공유 → 링크 복사 → 영상칸에 붙여넣기

영상이 쌓였다면 PC 유튜브 스튜디오에서 한 번에 드래그 업로드하는 편이 빠르다.

**링크 종류별 동작**

| 링크 | 앱에서 |
|---|---|
| 유튜브 (일반·쇼츠·youtu.be) | 인라인 재생 |
| 구글 드라이브 (`링크가 있는 모든 사용자`로 공유) | 인라인 재생 |
| mp4 / mov / m4v / webm 직링크 | 인라인 재생 |
| 구글 포토, 아이클라우드, 그 외 | 새 탭으로 열림 |

- 아이클라우드 "링크 복사"는 **30일 뒤 만료**되니 오래 보관할 영상에는 쓰지 않는다
- 영상은 탭했을 때만 불러오므로 데이터를 아낀다
- 같은 종목에 여러 날짜의 영상이 붙으면 종목 화면에 날짜별로 모두 모인다

## 기술 메모

- 순수 HTML/CSS/JS 단일 파일, 외부 라이브러리·네트워크 요청 없음 (유튜브 임베드 제외)
- 다크/라이트 테마 자동 + 우상단 ◐ 버튼으로 수동 전환
- 데이터 스키마 (v2, v1 데이터는 열 때 자동 이관)

```jsonc
{
  "version": 2,
  "sessions": [{
    "id": "s...", "date": "2026-08-03", "memo": "", "createdAt": 0,
    "exercises": [{
      "name": "루마니안 데드리프트",
      "part": "leg",                              // 자동 분류 결과
      "cues": ["호흡 마시고…"],                    // = 팁
      "sets": [{ "w": 40, "u": "kg", "r": 5 }],   // w=중량, u=단위, r=횟수, t=시간
      "declared": 5,                              // 원문에 적힌 세트 수
      "rawSets": "10kg x 15, …",
      "video": ""
    }]
  }],
  "parts": { "루마니안데드리프트": "back" },        // 사용자가 지정한 부위 (자동 분류보다 우선)
  "stars": { "바벨스쿼트|무릎이발끝방향…": true },   // 별표한 팁
  "notes": [{ "id":"n...", "ex":"바벨스쿼트", "exName":"바벨 스쿼트",
              "text":"발 너비는 어깨보다 살짝 넓게", "date":"2026-08-03" }]
}
```

팁 중복 판정은 공백·문장부호를 지운 문자열로 하므로, 표현이 조금 달라도(`,` 유무 등) 같은 팁으로 묶인다.
